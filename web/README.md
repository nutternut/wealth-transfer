# Wealth Transfer Web

Next.js app for family Wealth Map + Transfer Plan (mock data).

## Run

```bash
cd web
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS v4
- @dnd-kit — drag timeline steps + diagram nodes
- Mock data only (single-user local)
